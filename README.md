# 汐止阿坤3C工作室 購物網站 ─ 操作說明書

這份說明是寫給**完全不懂程式的人**看的。照著做就可以改店名、新增商品、換照片，甚至免費把網站放上網路。

---

## 1. 怎麼打開網站

網站已經上線了，網址是 **<https://itscharlie105-dotcom.github.io/kun3c/>**（更新方法看第 6 節）。

要在自己電腦上看、或是想先改好再上傳，**直接用滑鼠左鍵連點兩下 `index.html`**，
網站就會在瀏覽器打開，不需要安裝任何東西、不需要連網路。

- 建議用 Chrome 或 Edge 開啟。
- 八個頁面加一個老闆專用工具：
  | 檔案 | 用途 |
  | --- | --- |
  | `index.html` | 首頁 |
  | `products.html` | 全部商品（含篩選、搜尋、排序） |
  | `product.html` | 單一商品詳情（由商品卡點進去） |
  | `cart.html` | 購物車與結帳 |
  | `guide.html` | 購物須知／保固／常見問答 |
  | `about.html` | 關於我們／聯絡我們／收購詢價 |
  | `helper.html` | 選購小幫手（回答四個問題，自動推薦機器） |
  | `orders.html` | 訂單紀錄（客人查自己送出過的訂單） |
  | `新增商品工具.html` | **老闆專用**：填表新增商品與產生社團貼文（看第 3 節）；沒有連在導覽列上，客人逛網站不會看到 |
- 改完任何檔案後，記得存檔，然後在瀏覽器按 **F5**（Mac 按 **Cmd + R**）重新整理。
- 如果改了東西畫面沒變，按 **Ctrl + Shift + R**（Mac 按 **Cmd + Shift + R**）強制重新整理。

## 2. 怎麼改店名、電話、聯絡方式

全部都在 **`js/config.js`** 這一個檔案裡。用「記事本」或 VS Code 打開它，只改**單引號 `'` 中間的字**，不要刪掉逗號或大括號。

| 想改什麼 | 改哪一行 | 範例 |
| --- | --- | --- |
| 店名（中文） | `storeName:` | `storeName: '汐止阿坤3C工作室',` |
| 英文副標 | `storeNameEn:` | 留 `''` 就不會顯示英文副標 |
| 主標語 | `slogan:` | `slogan: '嚴選中古3C',` |
| 首頁副標 | `subSlogan:` | 一句話介紹 |
| **聯絡管道名稱** | `contactChannel:` | `contactChannel: 'Facebook',`（按鈕上會顯示這個字） |
| **聯絡連結** | `contactUrl:` | 客人按聯絡按鈕會連到這裡（目前是姊姊的 Facebook） |
| **聯絡人說明** | `contactNote:` | 顯示在每顆聯絡按鈕下面的小字，例如「訊息由店長的女兒代為回覆」。留空 `''` 就不顯示 |
| LINE ID | `lineId:` | 只有 `contactUrl` 留空 `''` 時才會用到 |
| 網站網址 | `siteUrl:` | 產生社團貼文時會附在文末，換網域時要改 |
| 電話 | `phone:` | `phone: '0916-237-275',` |
| Email | `email:` | `email: 'itscharlie105@gmail.com',` |
| 取貨方式 | `delivery:` | `delivery: '全台宅配 ＋ 汐止面交',` |
| 營業時間 | `hours:` | `hours: '每日 10:00–21:00',` |
| 宅配運費 | `shippingFee:` | `shippingFee: 160,`（數字不加引號） |
| 免運門檻 | `freeShippingThreshold:` | `freeShippingThreshold: 10000,` |

改一個地方，**八個頁面的頁首、頁尾、聯絡資訊、聯絡按鈕、瀏覽器分頁標題會全部自動更新**，不用一頁一頁改。

> 小提醒：只有給 Google 看的那一行說明文字（每個 `.html` 檔案開頭的 `<meta name="description">`）是寫死的。
> 如果店名整個換掉，想讓搜尋結果也更新，可以把七個 html 檔案開頭那一行裡的舊店名一起改掉；不改也不影響網站運作。

> **關於聯絡按鈕**：全站的聯絡按鈕（包含按鈕上的字、內文寫的「用 ○○ 傳給我們」）都是跟著
> `contactChannel` 和 `contactUrl` 這兩行走的。
>
> - 現在設定的是 **Facebook**，按鈕會顯示「用 Facebook 問問」，點了會開啟姊姊的 Facebook。
> - 以後申請到 **LINE 官方帳號**想換回 LINE：把 `contactUrl` 改成 `''`（空的）、
>   `contactChannel` 改成 `'LINE'`、`lineId` 填上你的 LINE ID，全站就會自動變回 LINE。
> - 如果兩個都留空，所有聯絡按鈕會自動改成導向「關於我們」頁面的詢價表單，**不會出現壞掉的連結**。

## 3. 怎麼新增一件商品（填表就好，不用寫程式）

資料夾裡有一個 **`新增商品工具.html`**，連點兩下打開它，照著做就好：

1. **填表格**：商品名稱、分類、品牌、售價⋯⋯填完按「**加入這件商品**」。
   要加好幾件就再填一次、再按一次。
2. **順便整理舊商品**：中間那張表是現有商品，
   賣掉的直接把**庫存改成 0**（會變灰色「已售出」），不想賣了就勾「**刪除**」。
3. **按「下載新的 products.js」**，瀏覽器會把檔案下載到「下載」資料夾。
4. **把下載到的 `products.js` 拖進網站資料夾裡的 `js` 資料夾**，
   跳出「要取代嗎？」選**取代**。
5. 雙擊 `index.html`，確認新商品有出現、數字正確。
6. 上傳到網路上（第 6 節），客人就看得到了。

> 這個工具只是幫你把表格變成檔案，**不會自己改到網站**，所以亂按也不會壞。
> 弄錯了就重新填一次、重新下載一次即可。

### 一定要填的只有四個

**商品名稱、分類、品牌、售價**。其他欄位留空也沒關係，會自動帶預設值。

### 填寫小提醒

| 欄位 | 怎麼填 |
| --- | --- |
| 售價、原價 | **只填數字**，不要打逗號或 NT$。原價留空就不會顯示折扣 |
| 成色 | 選 A+／A／B／C，標準寫在「購物須知」頁 |
| 保固天數 | 沒保固就填 0 |
| 庫存 | 填 0 會顯示「已售出」，商品仍留在網站上 |
| 規格 | 一行一個項目，例如「CPU」配「Intel i5-8265U」，不用填滿六行 |
| 賣點 | 一行一個，會變成一顆一顆的小標籤 |
| 瑕疵說明 | **誠實寫清楚**，商品頁會用琥珀色框強調，可以少掉很多客訴 |
| 照片檔名 | 先把照片放進 `images` 資料夾，這裡**一行填一個檔名**，可以放很多張；第一張是封面 |

### 進階：想自己動手改檔案

商品資料實際上存在 `js/products.js`，可以用「文字編輯」或 VS Code 直接打開修改，
每個欄位的意思寫在檔案最上面。手動改的時候要注意：

- 中文字要用單引號 `'` 包起來，數字不用
- 每一筆商品之間要有逗號，最後一筆後面不要加逗號
- 大括號 `{ }`、中括號 `[ ]` 都要成對

> 如果畫面變成一片空白，通常就是上面三點其中一個出錯。
> 最快的救法：打開「新增商品工具.html」重新產生一份乾淨的檔案蓋回去。

### 「這台適合做什麼」是自動算的

每台電腦的商品頁上會出現一張表，用五顆點標示文書、追劇、視訊課、多工、修圖剪片、玩遊戲
各自跑不跑得動，商品卡上也會顯示綠色的「✓ 文書 ✓ 追劇」小標籤。

**這些分數是程式從你填的規格（CPU、記憶體、硬碟、顯卡）自動算出來的，你不用多填任何欄位。**
電視與螢幕則會自動換成「建議觀看距離」「適合幾吋的桌面」這類建議。

如果覺得某一項算得不準（機器實際跑起來比分數好或差），可以在那件商品裡加一行 `fit` 蓋過去：

```js
fit: { game: 2, creative: 4 },
```

項目代號：`office` 文書／`web` 追劇／`meeting` 視訊課／`multi` 多工／`creative` 修圖剪片／`game` 玩遊戲，
分數填 1 到 5（5 最順）。沒寫到的項目仍然會自動計算。

> 評分規則寫在 `js/fit.js`，刻意抓得保守一點：**寧可客人拿到覺得比預期好，也不要寫得太美**。
> 商品頁下方也寫明了「這是依規格自動評估的參考值，不是實測跑分」。

### 選購小幫手會自動推薦機器

 會問客人四個問題（用途、要筆電還是桌機、預算、最在意什麼），
然後從**目前有庫存的機器**裡挑出最多三台，並寫出推薦理由。

- 推薦清單是即時算的，你改商品資料它就跟著變，**不用另外維護**
- 客人勾的用途只要有一項是 2 分以下（真的跑不動），那台就不會被推薦
- 預算內沒有符合的機器時，會自動放寬預算並標示「稍微超出預算」
- 完全沒有符合的時候，會引導客人去填「找機器需求單」

入口在：首頁（信任條下方的橫幅）、商品列表上方、頁首導覽列、頁尾快速連結。
**發社團貼文時也可以單獨貼這個連結**：，適合「不知道買什麼」的客人。

### 產生社團貼文（同一個工具裡）

打開 `新增商品工具.html`，捲到最下面的「**四、產生社團貼文**」（頁面最上方也有跳轉連結）。

1. **選貼文型式**
   - **單台詳細介紹**：勾 1 台，會產生完整規格、賣點、誠實說明、價格、成色、保固與商品頁連結
   - **多台上架公告**：勾 2 台以上，每台一行摘要，適合「本週新上架」這種貼文
   - **店家介紹**：不用勾商品，適合開張或久沒發文時用，會自動帶入目前的庫存台數
2. **勾要放進貼文的商品**（按「選最新 3 台」可以一次勾好）
3. 按「**複製貼文**」，直接貼到 Facebook 社團

貼文內容全部從商品資料自動產生，**規格不會漏寫、格式每次都一樣**，
電話、營業時間、運費、免運門檻也都是從 `js/config.js` 帶進去的，改設定貼文就跟著變。

**貼之前記得兩件事**：

- 先看社團規則，有些社團禁止貼外部連結，那就把網址放在**第一則留言**
- **第一張照片放實拍**，不要放網站截圖，不然看起來像廣告會被滑過去

## 4. 怎麼把示意圖換成真實照片

網站預設用程式畫的線條示意圖（不需要任何圖片檔）。想換成實拍照片時：

1. 在網站資料夾（和 `index.html` 同一層）新增一個資料夾，名字就叫 **`images`**。
2. 把照片放進去，檔名**只用英文與數字**，例如 `lap-01.jpg`、`tv-01.jpg`。
3. 打開 `js/products.js`，找到那件商品的 `images` 欄位，把照片路徑一張一張填進去：

   ```js
   images: [
     'images/lap-01-1.jpg',
     'images/lap-01-2.jpg',
     'images/lap-01-3.jpg'
   ],
   ```

4. 存檔、重新整理，該商品的列表與詳情頁就會自動改用真實照片，不再畫示意圖。

### 一台機器可以放很多張

- **第一張是封面**，會出現在商品列表的卡片上，卡片右上角自動顯示「N 張實拍」
- 詳情頁會出現縮圖列，客人點縮圖切換，**點大圖可以全螢幕放大**看細節
  （鍵盤也能操作：左右方向鍵換照片、Esc 關閉）
- 建議的拍攝順序：**整機外觀 → 開機畫面 → 鍵盤掌托 → 有瑕疵的地方 → 電池健康度或規格截圖**
  後面那兩張最能建立信任，因為那是「我沒有唬你」的證據
- 用「新增商品工具」填表時，照片欄位**一行填一個檔名**就好

**照片建議**：橫向、大小約 1200 x 900 像素、單張 250KB 以內，背景乾淨。
沒有填照片（`images: []`）的商品仍然會用示意圖，兩種可以混著用。

> 舊的單張寫法 `image: 'images/xxx.jpg'` 仍然可以用，不會壞掉。

> `images` 資料夾裡已經有一張 `owner.jpg`，那是首頁「店長本人」區塊用的老闆照片。
> 想換成別張：把新照片命名成 `owner.jpg` 蓋掉它就好（直式、人在畫面中間的照片效果最好）。

## 5. 訂單與客人來信（重要觀念）

`orders.html` 會列出「**在這台電腦上送出過的訂單**」，客人可以隨時回來重新複製訂單內容，再傳一次給你。

請記得這個重點：

- 這個網站**沒有後端伺服器**，訂單不會寄到任何信箱，也不會進到你的後台。
- 訂單紀錄是存在**客人自己那台電腦的瀏覽器**裡（技術名稱叫 localStorage）。
  客人換一台電腦、換瀏覽器或清除瀏覽資料，紀錄就會不見。
- **你在自己的電腦上打開 `orders.html`，只看得到你自己測試時送出的訂單，看不到客人的。**
  真正的訂單還是以客人私訊傳給你的那段文字為準，建議收到後另外存一份（例如貼到備忘錄或記事本）。
- 頁面上有「刪除這筆」與「清除全部紀錄」，按下去會先跳出確認視窗，確認後無法復原。

> 想在自己電腦上清掉測試用的訂單：打開 `orders.html`，按右上角的「清除全部紀錄」即可。

### 客人填的兩張表單會寄到哪裡？

「關於我們」頁面有兩張表單：

- **收購詢價單**：客人有舊電腦、舊電視想賣給你
- **找機器需求單**：客人想買的機型網站上沒有，留下需求等你通知

兩張表單填完按送出後，客人會看到三個按鈕：

1. **用 Email 寄給我們** → 自動開啟他的郵件軟體，收件者就是 `js/config.js` 裡的 Email，內容也都填好了，他按下寄出你就會收到信
2. **複製內容** → 自己貼到訊息裡傳
3. **用 Facebook 傳給店家** → 直接開啟聯絡管道

⚠️ 一樣要記得：網站沒有後端，**客人要自己按下「寄出」你才收得到信**，不是填完就會自動寄。
所以請養成習慣**定期收信**（目前設定的是 `itscharlie105@gmail.com`），
真正可靠的還是私訊那條路。

## 7. 資安與防騙（重要，請看完）

### 這個網站天生沒有的風險

因為是純靜態網站，下面這些常見的攻擊方式，**對這個網站根本用不上**：

- **沒有資料庫** → 不會被 SQL injection
- **沒有自己的伺服器** → 沒有主機被入侵、被植入後門的問題（檔案放在 GitHub 上）
- **沒有會員、沒有密碼、沒有線上刷卡** → 沒有客人個資或信用卡資料可以外洩
- **沒有使用任何外掛套件或 CDN** → 不會因為別人的套件被駭而受害
- **客人填的姓名電話地址只留在他自己的瀏覽器**，不會傳到任何地方

### 真正要小心的三件事

**1. GitHub 帳號被盜（最嚴重）**

有人拿到帳號，就能把網站上的電話、聯絡連結換成他自己的，客人就會把錢匯給他。

- 👉 **請到 <https://github.com/settings/security> 開啟「兩步驟驗證（2FA）」**
- 密碼不要跟其他網站共用
- 協作者也要開 2FA
- 絕對不要把帳號密碼給別人，要讓人幫忙就用「協作者」功能

**2. 有人複製網站冒充我們**

網站是公開的，任何人都能複製一份、把聯絡方式改成自己的，再去社團貼文騙錢。

- 在社團固定用同一個帳號發文
- 網站、名片、貼文上的網址要一致
- **匯款帳號只在私訊提供，絕不公布在網站上**（目前購物須知已經這樣寫）
- 提醒客人：匯款前一定要在私訊再確認一次帳號

**3. 訂單內容可以被改**

訂單文字是在客人的瀏覽器產生的，懂電腦的人可以改掉上面的金額再傳給你。

- **以網站上的標價為準**，收到訂單一定自己核對一次金額
- 金額對不上就直接在私訊跟客人確認，不要照單全收

### 已經做好的防護

- 全站 **https** 加密連線（GitHub Pages 提供）
- 加上 **內容安全政策（CSP）**：瀏覽器只允許載入本站自己的程式與圖片，
  就算有人想塞外部程式碼進來也會被瀏覽器擋掉
- 所有顯示在畫面上的文字都做過**跳脫處理**，不會變成可執行的程式碼
- 對外連結都加了 `rel="noopener"`，避免被連過去的網站反向操作
- 專案裡**沒有任何密碼、金鑰或帳號**

### 平常的好習慣

- 每週看一眼 <https://github.com/itscharlie105-dotcom/kun3c/commits/main>，
  確認每一筆改動都是自己人做的
- 真的被改壞了也不用慌：**每一個版本都存在 GitHub，隨時可以還原**
- 協作者不用了就移除：<https://github.com/itscharlie105-dotcom/kun3c/settings/access>

## 8. 技術備註（給日後協助維護的人）

- 純靜態網站：沒有建置流程、沒有 npm、沒有框架，`file://` 直接開啟即可運作。
- 不使用 `type="module"`、`import/export`、`fetch()` 讀取本地檔案，因此不會被 CORS 擋下。
- 資料以全域變數提供：`window.SITE_CONFIG`（`js/config.js`）、`window.PRODUCTS`（`js/products.js`）。
- 無任何外部連線：不載入 CDN、網路字型或外部圖片，離線也能完整運作。
- 購物車存在瀏覽器的 `localStorage`，鍵值為 `kun3c_cart`；歷史訂單為 `kun3c_orders`。
- 用途適合度由 `js/fit.js` 的 `window.getFitness(product)` 計算：解析規格文字取得 CPU 等級、記憶體、硬碟型態與顯卡，再換算成六種用途的 1～5 分；商品可用 `fit` 欄位覆寫個別項目。商品列表的「我要拿來做什麼」篩選會留下該用途 4 分以上的電腦。
- 商品示意圖由 `js/svg.js` 的 `window.getProductSVG(kind)` 產生；商品的 `images` 陣列一旦填入路徑就會自動改用真實照片（舊的 `image` 單張欄位仍相容）。詳情頁相簿支援縮圖切換、全螢幕放大、鍵盤左右切換與 Esc 關閉，關閉後焦點會回到原本的大圖。
- 分享預覽（貼到 Facebook／LINE 時顯示的圖卡）寫在每個 html 檔開頭的 `og:` 標籤，
  圖片是 `images/share.jpg`（1200x630）。**網址或店名改變時，這幾行要一起改**，
  七個檔案都有。商品頁因為是用 JavaScript 產生內容，Facebook 的爬蟲讀不到個別商品，
  分享任何商品頁都會顯示同一張店家圖卡。
- 已售出（`stock: 0`）的商品在任何排序下都會自動排到最後。
- 聯絡管道由 `contactChannel` / `contactUrl` 決定：HTML 內文用 `<span data-cfg="contactChannel">` 取得名稱，按鈕文字用 `{管道}` 佔位字串，由 `js/app.js` 的 `channelLabel()` 置換。
