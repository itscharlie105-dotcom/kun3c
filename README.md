# 汐止阿坤3C工作室 購物網站 ─ 操作說明書

這份說明是寫給**完全不懂程式的人**看的。照著做就可以改店名、新增商品、換照片，甚至免費把網站放上網路。

---

## 1. 怎麼打開網站

網站已經上線了，網址是 **<https://itscharlie105-dotcom.github.io/kun3c/>**（更新方法看第 6 節）。

要在自己電腦上看、或是想先改好再上傳，**直接用滑鼠左鍵連點兩下 `index.html`**，
網站就會在瀏覽器打開，不需要安裝任何東西、不需要連網路。

- 建議用 Chrome 或 Edge 開啟。
- 七個頁面加一個老闆專用工具：
  | 檔案 | 用途 |
  | --- | --- |
  | `index.html` | 首頁 |
  | `products.html` | 全部商品（含篩選、搜尋、排序） |
  | `product.html` | 單一商品詳情（由商品卡點進去） |
  | `cart.html` | 購物車與結帳 |
  | `guide.html` | 購物須知／保固／常見問答 |
  | `about.html` | 關於我們／聯絡我們／收購詢價 |
  | `orders.html` | 訂單紀錄（客人查自己送出過的訂單） |
  | `新增商品工具.html` | **老闆專用**：填表新增商品（看第 3 節）；沒有連在導覽列上，客人逛網站不會看到 |
- 改完任何檔案後，記得存檔，然後在瀏覽器按 **F5**（Mac 按 **Cmd + R**）重新整理。
- 如果改了東西畫面沒變，按 **Ctrl + Shift + R**（Mac 按 **Cmd + Shift + R**）強制重新整理。

## 2. 怎麼改店名、電話、聯絡方式

全部都在 **`js/config.js`** 這一個檔案裡。用「記事本」或 VS Code 打開它，只改**單引號 `'` 中間的字**，不要刪掉逗號或大括號。

| 想改什麼 | 改哪一行 | 範例 |
| --- | --- | --- |
| 店名（中文） | `storeName:` | `storeName: '汐止阿坤3C工作室',` |
| 英文副標 | `storeNameEn:` | 留 `''` 就不會顯示英文副標 |
| 主標語 | `slogan:` | `slogan: '嚴選中古3C',` |
| 首頁副標 | `subSlogan:` | 一句話介紹 |
| **聯絡管道名稱** | `contactChannel:` | `contactChannel: 'Facebook',`（按鈕上會顯示這個字） |
| **聯絡連結** | `contactUrl:` | 客人按聯絡按鈕會連到這裡（目前是姊姊的 Facebook） |
| LINE ID | `lineId:` | 只有 `contactUrl` 留空 `''` 時才會用到 |
| 電話 | `phone:` | `phone: '0916-237-275',` |
| Email | `email:` | `email: 'itscharlie105@gmail.com',` |
| 取貨方式 | `delivery:` | `delivery: '全台宅配 ＋ 汐止面交',` |
| 營業時間 | `hours:` | `hours: '每日 10:00–21:00',` |
| 宅配運費 | `shippingFee:` | `shippingFee: 160,`（數字不加引號） |
| 免運門檻 | `freeShippingThreshold:` | `freeShippingThreshold: 10000,` |

改一個地方，**七個頁面的頁首、頁尾、聯絡資訊、聯絡按鈕、瀏覽器分頁標題會全部自動更新**，不用一頁一頁改。

> 小提醒：只有給 Google 看的那一行說明文字（每個 `.html` 檔案開頭的 `<meta name="description">`）是寫死的。
> 如果店名整個換掉，想讓搜尋結果也更新，可以把七個 html 檔案開頭那一行裡的舊店名一起改掉；不改也不影響網站運作。

> **關於聯絡按鈕**：全站的聯絡按鈕（包含按鈕上的字、內文寫的「用 ○○ 傳給我們」）都是跟著
> `contactChannel` 和 `contactUrl` 這兩行走的。
>
> - 現在設定的是 **Facebook**，按鈕會顯示「用 Facebook 問問」，點了會開啟姊姊的 Facebook。
> - 以後申請到 **LINE 官方帳號**想換回 LINE：把 `contactUrl` 改成 `''`（空的）、
>   `contactChannel` 改成 `'LINE'`、`lineId` 填上你的 LINE ID，全站就會自動變回 LINE。
> - 如果兩個都留空，所有聯絡按鈕會自動改成導向「關於我們」頁面的詢價表單，**不會出現壞掉的連結**。

## 3. 怎麼新增一件商品（填表就好，不用寫程式）

資料夾裡有一個 **`新增商品工具.html`**，連點兩下打開它，照著做就好：

1. **填表格**：商品名稱、分類、品牌、售價⋯⋯填完按「**加入這件商品**」。
   要加好幾件就再填一次、再按一次。
2. **順便整理舊商品**：中間那張表是現有商品，
   賣掉的直接把**庫存改成 0**（會變灰色「已售出」），不想賣了就勾「**刪除**」。
3. **按「下載新的 products.js」**，瀏覽器會把檔案下載到「下載」資料夾。
4. **把下載到的 `products.js` 拖進網站資料夾裡的 `js` 資料夾**，
   跳出「要取代嗎？」選**取代**。
5. 雙擊 `index.html`，確認新商品有出現、數字正確。
6. 上傳到網路上（第 6 節），客人就看得到了。

> 這個工具只是幫你把表格變成檔案，**不會自己改到網站**，所以亂按也不會壞。
> 弄錯了就重新填一次、重新下載一次即可。

### 一定要填的只有四個

**商品名稱、分類、品牌、售價**。其他欄位留空也沒關係，會自動帶預設值。

### 填寫小提醒

| 欄位 | 怎麼填 |
| --- | --- |
| 售價、原價 | **只填數字**，不要打逗號或 NT$。原價留空就不會顯示折扣 |
| 成色 | 選 A+／A／B／C，標準寫在「購物須知」頁 |
| 保固天數 | 沒保固就填 0 |
| 庫存 | 填 0 會顯示「已售出」，商品仍留在網站上 |
| 規格 | 一行一個項目，例如「CPU」配「Intel i5-8265U」，不用填滿六行 |
| 賣點 | 一行一個，會變成一顆一顆的小標籤 |
| 瑕疵說明 | **誠實寫清楚**，商品頁會用琥珀色框強調，可以少掉很多客訴 |
| 照片檔名 | 先把照片放進 `images` 資料夾，這裡只要填檔名（例如 `lap-06.jpg`） |

### 進階：想自己動手改檔案

商品資料實際上存在 `js/products.js`，可以用「文字編輯」或 VS Code 直接打開修改，
每個欄位的意思寫在檔案最上面。手動改的時候要注意：

- 中文字要用單引號 `'` 包起來，數字不用
- 每一筆商品之間要有逗號，最後一筆後面不要加逗號
- 大括號 `{ }`、中括號 `[ ]` 都要成對

> 如果畫面變成一片空白，通常就是上面三點其中一個出錯。
> 最快的救法：打開「新增商品工具.html」重新產生一份乾淨的檔案蓋回去。

## 4. 怎麼把示意圖換成真實照片

網站預設用程式畫的線條示意圖（不需要任何圖片檔）。想換成實拍照片時：

1. 在網站資料夾（和 `index.html` 同一層）新增一個資料夾，名字就叫 **`images`**。
2. 把照片放進去，檔名**只用英文與數字**，例如 `lap-01.jpg`、`tv-01.jpg`。
3. 打開 `js/products.js`，找到那件商品的 `image` 欄位，把 `null` 改成照片路徑：

   ```js
   image: 'images/lap-01.jpg',
   ```

4. 存檔、重新整理，該商品的列表與詳情頁就會自動改用真實照片，不再畫示意圖。

**照片建議**：橫向、大小約 1200 x 900 像素、單張 300KB 以內，背景乾淨。一件商品目前支援一張主圖。
沒有填 `image`（維持 `null`）的商品，仍然會用示意圖，兩種可以混著用。

> `images` 資料夾裡已經有一張 `owner.jpg`，那是首頁「店長本人」區塊用的老闆照片。
> 想換成別張：把新照片命名成 `owner.jpg` 蓋掉它就好（直式、人在畫面中間的照片效果最好）。

## 5. 訂單紀錄頁是什麼（重要觀念）

`orders.html` 會列出「**在這台電腦上送出過的訂單**」，客人可以隨時回來重新複製訂單內容，再傳一次給你。

請記得這個重點：

- 這個網站**沒有後端伺服器**，訂單不會寄到任何信箱，也不會進到你的後台。
- 訂單紀錄是存在**客人自己那台電腦的瀏覽器**裡（技術名稱叫 localStorage）。
  客人換一台電腦、換瀏覽器或清除瀏覽資料，紀錄就會不見。
- **你在自己的電腦上打開 `orders.html`，只看得到你自己測試時送出的訂單，看不到客人的。**
  真正的訂單還是以客人私訊傳給你的那段文字為準，建議收到後另外存一份（例如貼到備忘錄或記事本）。
- 頁面上有「刪除這筆」與「清除全部紀錄」，按下去會先跳出確認視窗，確認後無法復原。

> 想在自己電腦上清掉測試用的訂單：打開 `orders.html`，按右上角的「清除全部紀錄」即可。

## 7. 技術備註（給日後協助維護的人）

- 純靜態網站：沒有建置流程、沒有 npm、沒有框架，`file://` 直接開啟即可運作。
- 不使用 `type="module"`、`import/export`、`fetch()` 讀取本地檔案，因此不會被 CORS 擋下。
- 資料以全域變數提供：`window.SITE_CONFIG`（`js/config.js`）、`window.PRODUCTS`（`js/products.js`）。
- 無任何外部連線：不載入 CDN、網路字型或外部圖片，離線也能完整運作。
- 購物車存在瀏覽器的 `localStorage`，鍵值為 `kun3c_cart`；歷史訂單為 `kun3c_orders`。
- 商品示意圖由 `js/svg.js` 的 `window.getProductSVG(kind)` 產生；商品的 `image` 欄位一旦填入路徑就會自動改用真實照片。
- 聯絡管道由 `contactChannel` / `contactUrl` 決定：HTML 內文用 `<span data-cfg="contactChannel">` 取得名稱，按鈕文字用 `{管道}` 佔位字串，由 `js/app.js` 的 `channelLabel()` 置換。
